规则与实现说明

  • 平均值两阶段传 Sum + Count；不同值个数传精确集合/单值中间状态，最后才计算 len。
  • 浮点键把 -0/+0 规范化为同一 bits，所有 NaN payload 规范化为同一组。
  • 字符串键只复制 string header；哈希逐字节读取原字符串，比较使用 Go 字符串原始字节比较。测试断言底层指针不变。
  • 估计分组很少时降为单线程全表汇总；高基数时跳过本地表并按 hash(key)%partition 透传；极多组自动扩分区，参数改动在下一批边界安全 reshard。
  • 检测到输入全程按键非递减时进入有序流：组切换即输出，不建哈希表；若发现逆序会自动重启为哈希路径。
